### 3.4 E 本轮实现清单

| 项 | 内容 |
|---|---|
| 修改接口 | PUT `/api/activities/{id}`，字段同创建接口，支持部分提交，未提交字段沿用原值 |
| 删除接口 | DELETE `/api/activities/{id}`，同一事务内先清理报名记录再删除活动 |
| 创建者权限 | 仅活动发布者可修改、删除；非发布者返回 403，活动不存在返回 404，未登录返回 401 |
| 活动状态 | 取值 招募中／已关闭；修改接口可置为已关闭，关闭后拒绝再次修改（409） |
| 人数上限 | 修改后不得小于当前报名人数，否则返回 400；上限仍须为正整数 |
| 涉及文件 | `backend/team_api.py`、`docs/API.md` |
